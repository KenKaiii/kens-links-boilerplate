## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Customization

Edit `config/site-config.ts` to update:
- Profile information (name, title, description)
- Social media links
- SEO metadata

Replace images in `/public/`:
- `images/profile-placeholder.png` - Your profile photo
- `og-image.png` - Social media preview image (1200x630px)

## Deploy to Vercel
